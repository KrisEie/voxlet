# Changelog

## 0.1.0 — first public release

- Native Windows dictation, reader and voice library with an English interface.
- English and Norwegian transcription; separate default reading voices.
- Optional Qwen English and Chatterbox V3 Norwegian reference-voice generation.
- Audio/video imports, Bokmål recording prompts, transcript review and voice deletion.
- Seeking, sentence navigation, global shortcuts and optional notification-area mode.
- Portable setup, a Windows ZIP and an empty personal voice library.

The initial public release is based on a locally developed app. This publication
includes original application source and artwork, but no personal recordings,
saved voice profiles, transcripts or machine-specific settings.
